# CVAT Object Detection Annotation Project

## Project Overview

This project demonstrates an object detection annotation workflow completed using CVAT (Computer Vision Annotation Tool).

The dataset contains product-related images that were manually annotated using bounding boxes and exported in COCO 1.0 format.

## Objective

The objective of this project was to create accurate object detection annotations by identifying and labeling objects in images according to predefined classes.

## Tools Used

* CVAT (Computer Vision Annotation Tool)
* COCO 1.0 Annotation Format
* JSON

## Annotation Classes

The project contains three object classes:

* `bottle`
* `box`
* `product`

## Project Statistics

* Images: 78
* Total annotations: 114
* Object classes: 3
* Export format: COCO 1.0

## Annotation Workflow

1. Imported the image dataset into CVAT.
2. Created the required annotation labels.
3. Annotated objects using bounding boxes.
4. Reviewed annotations for incorrect or missing labels.
5. Checked bounding-box placement and class assignment.
6. Exported the completed annotations in COCO 1.0 format.
7. Verified the exported JSON annotation file.

## Quality Control

The annotation process focused on:

* Correct object identification
* Correct class assignment
* Accurate bounding-box placement
* Avoiding unnecessary or duplicate annotations
* Reviewing annotations before export
